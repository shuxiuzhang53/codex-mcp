## 目标

打通以下工作流：

```text
Codex CLI
  -> paper-search-mcp 检索论文、筛选、下载开放获取 PDF
  -> zotero-mcp 创建 Zotero collection、导入文献、附加 PDF、打标签
  -> Codex 输出整理表格和阅读优先级
```

最终希望可以在 Codex 中输入类似：

```text
帮我检索某领域近几年论文，整理筛选，下载开放获取 PDF，并导入 Zotero。
```

2026-04-29 本地 Zotero 路线调整：

- 因为用户只安装了本地 Zotero 软件，已将 `~/codex-mcp/mcp-literature.env` 切换到 `ZOTERO_LOCAL="true"`。
- 本地模式不需要 Zotero Web API Key / Library ID。
- 需要打开 Zotero 桌面端，并在 Settings/Preferences -> Advanced -> API 启用 `Allow other applications on this computer to communicate with Zotero`。
- readiness 自检现在会检查 `http://127.0.0.1:23119/api/` 是否可达。
- 已确认当前 Codex shell 在 WSL2 + Codex sandbox 中运行；如果 Zotero 在 Windows 桌面端，`localhost:23119` 可能不能从当前 sandbox 访问。需要用 Windows PowerShell 验证 `curl.exe -i http://localhost:23119/api/`，或改走 Zotero Web API。

2026-04-29 Web API 路线调整：

- 如果 Zotero API Key 曾在不安全渠道（聊天、日志、截图等）出现过，应视为已泄露，到 Zotero 网站撤销并重新生成。
- 已新增 `~/codex-mcp/set-zotero-web-api-env.sh`，用于在本机终端静默输入新 key，避免写入聊天或 shell history。

- Web API 的 `ZOTERO_LIBRARY_ID` 对个人库应为 Zotero 页面显示的数字 User ID；用户名不等价。

- `paper-search-mcp` 的 PyPI 包当前未可靠暴露 `uv tool install` 命令入口；安装脚本已改为专用 venv + `python -m paper_search_mcp.server`。
